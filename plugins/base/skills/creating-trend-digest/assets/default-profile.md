# Trend Digest 興味プロフィール

このファイルはダイジェスト生成時のスコアリング基準。フィードバックのたびに
Claude が更新し、日々精度を上げていく。手動編集も自由。

## 興味テーマ

重みは high / mid / low の3段階。スコア倍率 (high=1.3 / mid=1.0 / low=0.6) に対応する。

- high: AIコーディングエージェント・開発ツール (Claude Code, LLM活用開発, エージェント設計)
- high: LLM・生成AIの新モデル/新技術動向
- mid: セキュリティ (特にAI×セキュリティ、Webセキュリティ)
- mid: JavaScript / TypeScript / Webフロントエンド
- mid: エンジニアのキャリア・組織論
- mid: 技術ブログの発信ネタになりそうな解説記事
- low: ガジェット・ハードウェア

## 除外テーマ

該当する記事はダイジェストに含めない。

- 政治・芸能ゴシップ
- 暗号通貨の価格変動の話題
